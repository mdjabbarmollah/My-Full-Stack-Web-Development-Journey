আমি একটা সাধারণ <div> — কোনো নিজস্ব স্টাইল/অর্থ নেই, শুধু গ্রুপিং এর জন্য ব্যবহার হয়।

p / br / hr

এটা একটা প্যারাগ্রাফ।
এই লাইনটা <br> দিয়ে নতুন লাইনে নেওয়া হয়েছে।

উপরে একটা <hr> দেখা যাচ্ছে — সেকশন আলাদা করতে ব্যবহার হয়।

blockquote / q / cite

এটা একটা বড় উদ্ধৃতি (blockquote) — সাধারণত অন্য কোনো সোর্স থেকে নেওয়া লম্বা টেক্সট দেখাতে ব্যবহার হয়।
— একটা কাল্পনিক বই

ছোট ইনলাইন উদ্ধৃতির জন্য: সে বলেছিল এখনই শুরু করো — এটা <q> ট্যাগ।

৩. ইনলাইন টেক্সট সেমান্টিক্স

strong = গুরুত্বপূর্ণ টেক্সট
em = জোর দেওয়া টেক্সট
b = শুধু বোল্ড স্টাইল
i = শুধু ইটালিক স্টাইল
u = আন্ডারলাইন
s = স্ট্রাইকথ্রু
small = ছোট টেক্সট
mark = হাইলাইট করা টেক্সট

৮. ইন্টারঅ্যাক্টিভ ট্যাগ
